# Coding Camp Software Engineering - RevoU

Proyek ini merupakan tugas dari program **Coding Camp Software Engineering RevoU**. Berupa aplikasi dashboard sederhana berbasis web yang dibuat menggunakan HTML, CSS, dan JavaScript.

## Fitur

- **Jam & Tanggal Real-time** — Menampilkan jam dan tanggal yang berjalan secara live.
- **Greeting** — Sapaan otomatis berdasarkan waktu (pagi, siang, sore, malam) dengan nama yang bisa diedit.
- **Focus Timer (Pomodoro)** — Timer fokus belajar yang bisa diatur durasinya, dilengkapi tombol Start, Stop, dan Reset.
- **Task Manager** — Fitur untuk menambah, menyelesaikan, dan mengurutkan daftar tugas.
- **Quick Links** — Menyimpan dan menampilkan tautan penting yang bisa diakses cepat.
- **Dark Mode** — Toggle untuk beralih antara tampilan terang dan gelap.

## Teknologi

- HTML5
- CSS3
- JavaScript (Vanilla)
- Tailwind CSS (via CDN)

## Cara Menjalankan

1. Clone repository ini.
2. Buka file `index.html` di browser, atau jalankan melalui lokal server seperti XAMPP.
